# CS-465-Fullstack

Architecture
In my full stack project, I used Express and HTML for server-side routing and rendering static content, while JavaScript handled client-side interactivity. The SPA framework allowed for dynamic content loading without page refreshes, providing a smoother user experience. The backend used a NoSQL MongoDB database because it offers flexibility in handling unstructured data, scalability, and efficient querying for document-based storage.

Functionality
JSON is a lightweight data format used to transfer data between the frontend and backend, while JavaScript is a programming language that manipulates data and logic. In the full stack process, I refactored code to modularize UI components, improving code reusability, readability, and efficiency, resulting in faster development and easier maintenance.

Testing
API testing in a full stack application involves testing various endpoints to ensure proper request handling and response formats, while security testing checks for vulnerabilities like unauthorized access. The complexity arises from securing sensitive data through encryption, authentication, and proper error handling.

Reflection
This course helped me build practical skills in full stack development, including using modern web technologies like React, Node.js, and MongoDB. I’ve developed problem-solving skills, learned to write efficient, maintainable code, and improved my understanding of deploying and managing web applications, all of which enhance my marketability as a developer.
